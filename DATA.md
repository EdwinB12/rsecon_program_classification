RSECon is a conference focused on Research Software Engineering (RSE). We have a list of links to oxford abstracts for each event in the RSECon programme `programmes/RSECon25_session_urls.txt`. On each link, there should be a 'presentation type'. This can be one of:

- Social
- Satellite Event
- Plenary
- Talk
- Presentation
- Workshop
- Birds of a Feather

If there isn't a presentation type, then its likely a logistic event such as a break, registration, or a meal. We are not interested in this events.

On each oxford page, there will be an 'in this session' section. This will contain a link to the presentation and its abstract.
